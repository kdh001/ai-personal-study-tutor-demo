# AI Personal Study Tutor — 합성 데이터 데모

개념을 읽고 단답 문제를 푼 뒤 오답과 다음 복습 간격을 확인하는 **로컬 데모**입니다. 개인 학습용 AI 튜터 프로젝트의 복습 간격 갱신 함수를 발췌하고, 공개 검토를 위해 합성 예제와 경량 웹 화면을 새로 구성했습니다.

## 실행

Python 3.11 이상만 필요합니다. 외부 패키지 설치, API 키, 인터넷 연결 없이 실행합니다.

```bash
python3 app.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 다른 포트나 데이터 파일을 쓰려면 `python3 app.py --port 8001 --db demo.sqlite3`을 실행합니다. Ctrl+C로 종료합니다. 학습 기록은 지정한 SQLite 파일에 저장되며, 초기화하려면 서버를 종료한 뒤 **직접 만든 데모 DB**를 지우면 됩니다.

개인 기록이 담길 수 있는 데모 DB는 공개 자료에 포함하지 마세요. `.gitignore`는 일반적인 DB 확장자를 제외하지만, 직접 정한 다른 파일명까지 모두 보호하지는 않습니다.

## 해볼 수 있는 것

- 새로 작성한 두 개념의 설명과 단답 문제를 읽고 채점합니다.
- 틀리면 정답과 해설을 확인하고 다시 풀 수 있습니다. 오답은 즉시 재복습 상태가 되며, 복습 예정일 이후 정답을 맞히면 1·3·7·14·30일 간격으로 갱신됩니다. 예정일 전에 맞힌 연습은 간격을 늘리지 않습니다. 예정일 전이라도 틀리면 즉시 재복습으로 바뀝니다.
- 모의 튜터 버튼은 미리 준비된 설명을 반환합니다. AI 모델이나 외부 서비스에 연결하지 않습니다.
- 복습 상태는 SQLite에 저장되어 재시작 후에도 유지됩니다.
- 복습 예정 시각은 브라우저의 현지 시간으로 표시합니다. 화면을 열린 채로 예정 시각이 지나면 새로고침해 상태를 갱신하세요.

## 테스트

```bash
python3 -m unittest -v test_demo
```

별도 임시 DB와 로컬 HTTP 서버를 사용해 복습 간격, 오답·정답·재시작, 입력과 출처 검사를 확인합니다.

## 범위와 한계

여기 포함된 설명·문제·답은 공개 데모를 위해 새로 만든 합성 예제입니다. 원본의 Next.js·FastAPI 전체 앱, PDF 분석, 개념 트리 생성, 실제 AI 대화·서술형 채점, 자료 업로드, 복습 큐·일정 알림, 기존 학습 DB, 교재와 사용자 기록은 포함하지 않았습니다. 복습 간격 갱신 외의 화면·서버는 공개 데모용으로 별도 작성했습니다. 원본 함수 앞에 예정일 전 반복 정답의 간격 증가를 막는 데모용 조건을 추가했습니다. 사용자의 학습 성과를 검증하거나 운영 서비스를 제공하는 제품은 아닙니다. 인증 기능이 없으므로 로컬에서만 사용하세요.

## 개발과 출처

개인 학습을 돕는 프로젝트를 AI 도구의 도움을 받아 개발했습니다. 이 데모의 `scheduler.py` 내 `sm2_update` 함수와 간격표는 원본 프로젝트의 복습 스케줄러에서 발췌했고 카드 모델·화면·서버·테스트는 데모에 맞춰 구성했습니다. 구체적인 개인별 기여 및 공동 작업 권리는 공개 전 확인이 필요합니다. 프로젝트 전체 라이선스는 아직 정하지 않았습니다.
